# CairoVolt reference tables

Small reference tables compiled from **published standards, not measurements**:

- [`docs/usb-pd-power-levels-reference.csv`](docs/usb-pd-power-levels-reference.csv) - USB Power Delivery voltage, current and power levels (SPR, EPR, PPS ranges).
- [`docs/lithium-battery-air-travel-wh-limits-reference.csv`](docs/lithium-battery-air-travel-wh-limits-reference.csv) - the commonly applied airline cabin rule for power banks (100 Wh / 160 Wh).

Always confirm against the current [USB-IF Power Delivery specification](https://www.usb.org/usb-charger-pd) and your airline's rules ([FAA guidance](https://www.faa.gov/hazmat/packsafe/more_info/?id=7)).

Documentation: see the `docs/` folder (built with MkDocs).
